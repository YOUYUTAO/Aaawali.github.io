ESP32-S3 固件 · 浏览器烧录

使用 USB 连接开发板，在 Chrome 或 Edge（桌面版）中打开本页， 点击下方按钮，按提示选择串口即可烧录。需 HTTPS（GitHub Pages 默认满足）。

  • 芯片：ESP32-S3，Flash 16MB，DIO / 80MHz（与 idf.py flash 一致）
  • 分区：bootloader、分区表、OTA 初始数据、应用 xiaozhi.bin、资源 generated_assets.bin
当前浏览器不支持 Web Serial，请用 Chrome 或 Edge 桌面版打开。 请通过 HTTPS 打开本页（例如 GitHub Pages）。

若按钮无反应或提示找不到文件：请确认已将构建产物复制到本站 firmware/ 目录（见同目录 firmware/README.md），并已启用 GitHub Pages 指向 /docs 或包含 web-flash 的路径。

EN: Connect the board via USB. Use Chrome or Edge (desktop). Click the button and grant serial access. Firmware binaries must be hosted under firmware/ next to this page (same origin) unless you change manifest.json to absolute URLs.
